# xhs-note-fetch

小红书**单条笔记**「提取 + 加工」双段流水线，给 AI Agent 用。

- **提取段**：一条命令把一条笔记变成成套素材 —— 标题 / 作者 / 发布时间 / 正文 / 标签 / 全部原图 / 视频直链，外加一份完整度 `manifest.json`（哪张缺了、为什么缺）。
- **加工段**：把长图/截图里的内容转录成**可追责**的结构化数据（题库、清单、教程步骤），带**证据分级 A/B**、三级 verdict、多源核验三步收口，并用机器校验卡一道再交付。

## 为什么需要它

小红书游客态**不下发服务端数据** —— 直接请求页面只能拿到空壳，取不到笔记主体。本技能改用**真实浏览器渲染**拿到完整数据：

> **不需要登录账号 · 不需要付费接口 · 不需要反复换链接。**

代价是要有一个可见的浏览器窗口（`agent-browser` 的有头 Chromium）—— 这是"免登录"换来的。

而"图里写的是什么、为什么可信"这件事，常被忽略。本技能的加工段把它做成**可追责**的：每个结论都带证据分级与依据。

## 特点

- **会话隔离**：只使用自己命名的浏览器会话，结束时只关自己开的，不会打断你机器上其他并行任务。
- **域名白名单**：下载只放行小红书自有域名族，页面数据被篡改也引不到外部 host。
- **断点续跑**：每张图即时落盘，中断重跑只补缺、不重下。
- **读图预算**：逐张读图前先降采样并估算 token，长图常见省 30%–60%。
- **防注入隔离**：笔记内容一律按不可信数据处理，其中的指令性文本不执行、并显式报出。
- **出口码可分流**：`full` / `partial`（可交付但要声明缺哪张）/ 链接失效 / **风控 300012** / 页面结构变更 —— 每种都有独立退出码，脚本不猜。

## 依赖

- Python 3.9+（脚本全部**纯标准库**）
- `agent-browser`（有头 Chromium）—— 提取段用
- macOS 自带 `sips` —— 降采样用（其他系统可跳过该步）
- 网络可达 `xiaohongshu.com`

## 用法

```bash
python3 scripts/fetch_note.py "<笔记URL>" "<输出父目录>" [--max-images=12]
python3 scripts/shrink_for_read.py "<产物目录>"
python3 scripts/verify_structured.py <结构化.json> --schema qa
```

触发场景、退出码表、加工段口径与已知坑，详见 `SKILL.md`。

## 合规

仅用于**自己有权查看**的内容（自己收到的分享链接 / 自己发的笔记），**单条提取、不做批量爬取、不重新分发素材**。

## 离线自证
