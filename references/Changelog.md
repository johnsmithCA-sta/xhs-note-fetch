# xhs-note-fetch 版本发布说明

> 只写使用者能感知的变化：新增能力 / 优化体验 / 修复问题 / 调整边界 四类。

## 2.2.0 版本发布（2026-09-30）

- 调整定位表述：明确本技能的长板是「不用登录、不用付费、不用反复换链接」拿到单条笔记，以及把长图内容变成可追责的数据。
- 调整全文用词，与「单条提取、不批量爬取」的使用边界保持一致。
- 补充安装前须知：运行时会弹出一个可见浏览器窗口，避免按「纯命令即可运行」的预期安装。

## 2.1.0 版本发布（2026-09-30）

- 新增失败原因区分：链接不对与 IP 被风控不再共用一个提示，风控会被单独报出，并提示立即停止重试。
- 新增图片处理张数上限，长图笔记可以限定本次处理多少张。
- 优化中断恢复：中途中断后重跑，已经取到的图片不会重复下载。
- 优化读图成本：逐张读图前先生成较小的副本并给出用量估算，长图通常可省三到六成。
- 优化浏览器收尾：只关闭本次任务自己打开的浏览器，不再影响你机器上其他正在运行的任务。
- 优化下载安全：只从官方图片与视频地址下载，范围外的地址一律丢弃并提示。
- 修复笔记内容可能干扰后续处理的问题：笔记正文里的指令性文字一律不执行，并会明确提示出来。
- 修复部分失败场景下的提示不准确、容易被误读为「换个链接就行」的问题。
- 补充版本信息与使用说明，安装前可获取的信息更完整。

## 2.0.0 版本发布（2026-09-29）

- 新增一条命令产出成套素材：标题、作者、发布时间、正文、标签、全部原图、视频地址，并附一份完整度清单，说明缺了哪张、为什么缺。
- 新增长图内容的结构化输出：题库与清单两种格式，每条结论标注证据等级与依据来源。
- 新增交付前的自动校验：必填项是否齐全、题号是否连续、答案是否落在选项内、证据等级是否写明依据。
- 优化取图方式：按官方图片清单取图，不再从页面结构里翻找，避免漏图。
- 调整视频处理：默认只记录地址，需要文件时再加参数下载，避免误下大文件。

## 1.2.0 版本发布（2026-09-29）

- 修复取图不全的问题：按官方图片清单取图，不再按链接前缀筛选。
- 调整下载来源要求：不再强制要求来源页标识。
- 修复下载文件打不开的问题：按文件真实格式命名，不再按链接后缀命名。
- 调整推荐流用法说明：可以自己从推荐流取练手样本，只有搜索页需要登录。

## 1.1.0 版本发布（2026-09-29）

- 新增场景路由说明：只想看内容、要视频文件、要看热榜分别该怎么做。
- 新增链接来源说明：链接需带分享标识，并说明三种获取途径。
- 新增完整度核对：图片数量对账、重复图去重、空图剔除，交付时明确说明完整度。
- 新增使用频率与风控提示：单次条数上限、条与条之间的间隔，遇到风控应立即停止。
- 新增使用边界声明。
- 修复链接无效时的提示：说明失败原因是回落到了推荐流，并给出自检。

## 1.0.0 版本发布（2026-09-29）

- 首个版本：从小红书笔记链接取出正文、图片与视频信息。
