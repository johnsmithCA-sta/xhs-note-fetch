# xhs-note-fetch 版本变更史

> 用户侧口径：只记「有什么变化、影响什么」，不记开发过程。

## v2.2.0 — 2026-09-30

**定位调整 + 术语对齐**（无功能变更，脚本行为与 v2.1.0 一致）。

- **定位更准确**：卖点从「抓取能力强」改为 **「免登录 / 免付费 / 免换链接」拿到单条笔记 + 把长图变成可追责数据**。
  - 原因：覆盖面上本技能只做小红书单条，不适合按"平台多、功能全"去比；而"免登录可用"与加工侧的"可追责"才是真实的长板。
- **术语对齐**：`抓取段 / 抓取` → **`提取段 / 提取`**（中性表述，与"单条提取、不批量爬取"的合规边界一致）。
- **说明补充**：明确写出依赖成本（需要一个可见浏览器窗口）与「为什么用它」一节，避免使用者按"纯命令即可跑"的预期安装。

## v2.1.0 — 2026-09-30

依一次内部生产就绪度评审给出的 7 条修复清单逐条落地。

**行为变更（请留意）**

- **浏览器会话隔离**：脚本改用**自己的命名会话**（默认 `xhs-note-fetch`，可用环境变量 `XHS_BROWSER_SESSION` 覆盖），结束时**只关自己开的会话**。
  - 修复原版「每次启动无条件 `agent-browser close --all`」——那会杀掉全机其他 agent-browser 会话（并行任务被静默打断）。
  - 新增 `--keep-open`：跑完不关会话，便于调试。
- **新增退出码 5（命中风控 300012）**，与退出码 2（无 token 回落推荐流）**分开**。
  - 原版两者共用 2，会把"IP 被风控"误判成"换链接重试"——而换链接对风控无效、硬刚只会加重。
- **新增降采样前置**：`shrink_for_read.py` 在逐张读图前生成 `_read/` 降采样副本并估算 token 预算（长图常见省 30%–60%）；修掉原版"逐张读图无预算、无上限"。
- **断点续跑**：下载循环内**每张图即时落盘**台账；重跑时 URL + md5 匹配的图直接复用，不重下。修掉原版"循环全部结束才写 manifest、中断零进度、重跑全量重下"。
- **新增 `--max-images=N`**：图片下载张数上限。
- **下载域名白名单**：默认只放行小红书自有域名族（`xhscdn.com` / `xiaohongshu.com`），白名单外直接丢弃并告警；`--allow-host` 可显式追加。
- **不可信内容隔离**：笔记正文/标题/标签自动扫描"指令样文本"，命中即告警并记入 `manifest.untrusted_flags`；产物头部加不可信声明块。加工段新增硬条款：笔记内的指令性文本一律不执行。
- **`--selftest` 扩到 4 组 15 项**（原 3 用例）：新增域名白名单、注样探测、JSON 解析 4 形态。
- **新增 `offline_demo.py`**：下载环节离线自证（本地假服务，不碰真实账号）。
- **元数据补全**：frontmatter 增 `slug` / `displayName` / `summary` / `license` / `author` / `homepage` / `last_updated` / `tags`；退出码文档与实现对齐（补 exit 1，改写 partial 描述）。

## v2.0.0 — 2026-09-29

从「抓取手册」升级为「抓取 + 加工双段流水线」。

- 新增 `scripts/fetch_note.py`：抓取段一条命令 → 渲染 → 取 `__INITIAL_STATE__` 整份元数据 → 下载 → magic bytes 判格式 → md5 去重 → manifest 完整度。
- 新增 `scripts/verify_structured.py`：加工段质量闸门（六类检查 + 答案键 baseline 快照比对 + `--selftest`）。
- 取消 DOM 抠图，改取 `imageList`（老写法会漏图）。
- 视频默认只记直链，`--download-video` 才拉。

## v1.2.0 — 2026-09-29

- 修图片筛选条件（按 `imageList` 取，不再按字符串前缀筛）。
- Referer 由「必须」降为「建议」。
- 下载物按 magic bytes 命名（实为 WebP）。
- 修正「无法自取 token」的旧结论：`/explore` 推荐流可自取，只有搜索页要登录。

## v1.1.0 — 2026-09-29

- 新增「30 秒路由判断」章节、H2 链接来源硬约束、完整性三查、批量与风控纪律、合规边界声明。
- 修正「无 token 会被拒」→ 实际是**静默 302 回落推荐流**，加 URL 自检。

## v1.0.0 — 2026-09-29

首版：基于 headed 浏览器渲染取 `__INITIAL_STATE__` 的抓取流程。
